# Tyre-Defect-Identification-System
TyreVision is an AI-powered tyre defect inspection platform developed to identify visible tyre defects from images. The system combines an EfficientNet-B0 deep learning model with a React frontend and Flask backend to provide defect classification, confidence scores, severity assessment, image quality analysis, Grad-CAM explainability, uncertainty analysis, tyre health scoring, and standards-aware inspection guidance. The platform is designed as an intelligent decision-support tool for tyre inspection and can be extended with multi-view inspection, defect localization, and X-ray analysis in future developments.
